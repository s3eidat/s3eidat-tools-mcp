### `text_case` — Case convert

Convert text case: upper, lower, title (smart: keeps small words lower and iPhone/NASA as typed), sentence, camel, pascal, snake, kebab, constant, alternate, inverse. Works line by line and handles Unicode (Arabic, accents, ß). Web version: https://s3eidat.github.io/case-convert/

Hints: readOnly, idempotent

**Inputs**

| Name | Type | Required | Description |
|---|---|---|---|
| `text` | string | yes | Text to convert. |
| `mode` | "upper" \| "lower" \| "title" \| "sentence" \| "camel" \| "pascal" \| "snake" \| "kebab" \| "constant" \| "alternate" \| "inverse" | yes | Target case. |

**Output**

| Field | Type | Description |
|---|---|---|
| `result` | string |  |

**Example**

```json
{
  "text": "a tale OF two cities",
  "mode": "title"
}
```

Result:

```json
{
  "result": "A Tale of Two Cities"
}
```

**Example**

```json
{
  "text": "XMLParser handler",
  "mode": "snake"
}
```

Result:

```json
{
  "result": "xml_parser_handler"
}
```

### `text_word_count` — Word count

Count words, characters (with and without spaces), sentences, paragraphs, lines and unique words; estimate reading (238 wpm) and speaking (150 wpm) time; list the most used keywords with density. Works for English and Arabic (tashkeel ignored). Give "text" or a text file "path". Web version: https://s3eidat.github.io/word-count/

Hints: readOnly, idempotent

**Inputs**

| Name | Type | Required | Description |
|---|---|---|---|
| `text` | string | no | The text to analyse. |
| `path` | string | no | Or: a path to a UTF-8 text file. |
| `keywords` | integer | no (default `12`) | How many top keywords to return (0 = none). |
| `includeStopWords` | boolean | no (default `false`) | Count common words like "the"/"في" as keywords. |

**Output**

| Field | Type | Description |
|---|---|---|
| `words` | number |  |
| `characters` | number |  |
| `charactersNoSpaces` | number |  |
| `sentences` | number |  |
| `paragraphs` | number |  |
| `lines` | number |  |
| `uniqueWords` | number |  |
| `averageWordLength` | number |  |
| `longestWord` | string |  |
| `readingTimeSeconds` | number |  |
| `speakingTimeSeconds` | number |  |
| `keywords` | object[] |  |

**Example** — 11 words, 4 sentences, 2 paragraphs

```json
{
  "text": "Hello world. This is a test! Is it?\n\nNew paragraph here."
}
```

### `hash_compute` — Hash (MD5 / SHA)

Compute MD5, SHA-1, SHA-256 and SHA-512 of text or a file (path or base64), optionally an HMAC with a key, and check against an expected checksum (hex in any case/spacing, "SHA256 (file) = …" lines, or base64). Web version: https://s3eidat.github.io/hash-lab/

Hints: readOnly, idempotent

**Inputs**

| Name | Type | Required | Description |
|---|---|---|---|
| `text` | string | no | Text to hash (UTF-8). |
| `file` | string | no | Or: a file to hash: local path or base64. |
| `hmacKey` | string | no | If set, also compute HMAC with this key. |
| `hmacAlgorithm` | "SHA-1" \| "SHA-256" \| "SHA-384" \| "SHA-512" | no (default `"SHA-256"`) |  |
| `format` | "hex" \| "HEX" \| "base64" | no (default `"hex"`) | Output encoding. |
| `expected` | string | no | A checksum to compare against; the result says which algorithm matched. |

**Output**

| Field | Type | Description |
|---|---|---|
| `bytes` | number |  |
| `hashes` | object |  |
| `match` | string \| null |  |

**Example** — SHA-256 = ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad

```json
}
```
