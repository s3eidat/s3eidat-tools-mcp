Install

Needs Node.js 20.19+ (22+ recommended). Pick your app:

claude mcp add s3eidat -s user -- npx -y s3eidat-tools-mcp

One click: download the .mcpb for your computer from the latest release and double-click it. No Node.js needed.

Or by hand: Settings → Developer → Edit Config → add this to claude_desktop_config.json, then restart Claude.

{
  "mcpServers": {
    "s3eidat": { "command": "npx", "args": ["-y", "s3eidat-tools-mcp"] }
  }
}

Windows: if npx isn't found, use "command": "cmd" and "args": ["/c", "npx", "-y", "s3eidat-tools-mcp"].

Private by design

Local

The server is a Node process on your machine. Files are read and written on your disk, never uploaded.

Sandbox it

--root ~/Documents keeps every read and write inside one folder.

No telemetry

No analytics, no accounts, no keys. The few agent tools that use the network are marked so your app asks first.

Same results as the web

Each tool is ported from its web version with the same self-tests, and links to it for humans.

Options

OptionWhat it does
--root <dir>Only allow reading and writing inside this folder.
--out-dir <dir>Default folder for outputs (otherwise a temp folder).
--max-mb <n>Largest input file in MB (default 200).
--groups pdf,imageOnly expose these groups (pdf, image, text, data, dev, calc, everyday, qr, docs, ai).
--compact3 small meta-tools (find, info, run) instead of ~140 tools. Best for Cursor/Windsurf tool limits and small models.
--http --port 8787Serve Streamable HTTP on 127.0.0.1 instead of stdio.
